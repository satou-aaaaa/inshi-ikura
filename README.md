# 印紙いくら？（inshi-ikura）

領収書や契約書の場面と金額（家具の代金99万円の領収書・土地の売買契約書・家の工事の請負契約書 など）を読んで、貼る収入印紙の額（いらない・200円・400円…）を当てる1日5問の学習ゲーム。正解したら「どの文書？」（7つ）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/inshi-ikura/>

- 答えは、国税庁タックスアンサー No.7105（領収書）・No.7140／No.7141（印紙税額の一覧表）・No.7108（不動産の譲渡、建設工事の請負に関する契約書の軽減措置）の表から計算しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）。
  - <https://www.nta.go.jp/taxes/shiraberu/taxanswer/inshi/7105.htm>
  - <https://www.nta.go.jp/taxes/shiraberu/taxanswer/inshi/7140.htm>
  - <https://www.nta.go.jp/taxes/shiraberu/taxanswer/inshi/7141.htm>
  - <https://www.nta.go.jp/taxes/shiraberu/taxanswer/inshi/7108.htm>
- 不動産の譲渡と建設工事の請負の軽減措置は、令和9年3月31日までに作る契約書の額です。消費税額を分けて書いた場合・電子で作った領収書・印紙を貼り忘れたときのことは出しません。場面と会社・店はつくりものです。
- このゲームは印紙税のしくみを知る練習です。税の相談の代わりではありません。実際の文書は、国税庁の資料や税務署で確かめてください。
